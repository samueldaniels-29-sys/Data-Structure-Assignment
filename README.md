## Assignment Description
This repository contains C programs for **Programming Assignment - 2** based on the applications of **Stack and Queue**.

The assignment includes the following programs:

1. **Reverse a String using Stack**
   - Reverses a given string using stack operations.

2. **Balanced Parentheses**
   - Checks whether the parentheses in an expression are balanced.

3. **Next Greater Element**
   - Finds the next greater element for each element in an array using a stack.

4. **Printer Queue Simulation**
   - Simulates a printer queue system using queue operations.

5. **Circular Queue Basic Operations**
   - Implements enqueue, dequeue, peek, and display using a circular queue.
